Java Libraries предоставляет скриптам AutoJs6 три библиотеки Java: Apache Commons Lang3, Apache Commons IO и Jackson. Если плагин включён, скрипты, как и раньше, используют их классы по полному имени, так же как в AutoJs6 6.7.0 и более ранних версиях.

### Начало работы

1. Убедитесь, что этот плагин включён в Центре плагинов AutoJs6.
2. Используйте в скрипте классы библиотек по полному имени, например `org.apache.commons.io.IOUtils`; пример приведён ниже.
3. Версии, артефакты Maven и пакеты Java каждой библиотеки показаны на странице плагина, которая открывается из Центра плагинов или значком Java Libraries на главном экране.

### Основные возможности

- **Библиотеки**: на странице плагина перечислены версии, артефакты Maven, пакеты Java и лицензии Apache Commons Lang3, Apache Commons IO и Jackson.
- **Использование в скриптах**: на странице плагина есть пример, который можно запустить как есть; в комментариях указан вывод каждой строки.
- **Файлы NOTICE**: на странице плагина показаны файлы NOTICE в том виде, в каком их публикуют библиотеки.

### Использование в скриптах

Используйте классы по полному имени; в комментариях указан вывод каждой строки:

```js
let StringUtils = org.apache.commons.lang3.StringUtils;
console.log(StringUtils.isBlank("  ")); // true
console.log(StringUtils.capitalize("autojs6")); // Autojs6

let IOUtils = org.apache.commons.io.IOUtils;
let input = new java.io.ByteArrayInputStream(new java.lang.String("hello").getBytes("UTF-8"));
console.log(IOUtils.toString(input, "UTF-8")); // hello

let mapper = new com.fasterxml.jackson.databind.ObjectMapper();
let tree = mapper.readTree('{"name": "AutoJs6", "version": 6}');
console.log(tree.get("version").asInt()); // 6
console.log(mapper.writeValueAsString(tree)); // {"name":"AutoJs6","version":6}
```

- Можно также сначала вызвать `importClass(org.apache.commons.lang3.StringUtils)`, а затем писать просто `StringUtils`.
- Если плагин недоступен, само упоминание класса не вызывает ошибку (Rhino считает ненайденное имя Java-пакетом); ошибка возникает, когда скрипт вызывает метод, создаёт объект или передаёт имя в `importClass`.

### Требования

- Android 7.0 или новее и AutoJs6 6.8.1 или новее.
- Плагин - это лишь пакет ресурсов: скрипты не запускают его процесс, и он не требует разрешений; скрипты, которые не обращаются к этим классам, не затронуты.

### Частые вопросы

**Скрипт не может использовать эти классы**

Убедитесь, что плагин установлен и включён в Центре плагинов, а версия AutoJs6 не ниже 6.8.1. Когда скрипт завершается такой ошибкой, AutoJs6 после ошибки в консоли подсказывает, нужно ли установить, авторизовать, включить или обновить плагин; ошибки, которые скрипт сам перехватывает через `catch`, такой подсказки не получают.

**Использование в упакованных приложениях**

При упаковке AutoJs6 берёт классы этого плагина с собой, если в скриптах есть имя, начинающееся с `org.apache.commons.lang3`, `org.apache.commons.io`, `com.fasterxml.jackson`; если просмотр такое имя не находит, отметьте Java Libraries в списке библиотек на странице упаковки. Приложение с этими классами может использовать их на устройствах без этого плагина; иначе оно использует плагин, установленный на устройстве.
